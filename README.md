# Git & Github Tutorial

## This repo use Git and Github Note

### Git clone

- terminal or CMD open then git clone < repository link>
- Add new file name use ( git clone < repository line> "file name " )

### Download Zip (Use project Repository)

- copy repo link then open cmd then write commands
- curl -L -o < file name.zip > < repo link /archive/"branch name" >
- example ( curl -L -o tuhhin.zip https://github.com/Mahafujmr/flutter_setState_practice/archive/main.zip )
